## Short Description

`mobile/` è uno scaffold Expo/React Native di SickFit con una schermata segnaposto, non un client mobile di prodotto.

## Description

La directory dichiara Expo, React Native e TypeScript e mostra una schermata iniziale descrittiva. Non contiene autenticazione, navigazione o flussi SickFit verificati. L’app nativa futura è distinta dalla PWA responsive in `frontend/`.

## Dependencies And Relationships

L’obiettivo mobile è usare in futuro l’identità e i servizi SickFit condivisi. API, callback, storage sicuro, dipendenze installate, build e runtime restano da implementare o verificare.
