Creare una tabella del db
1. crea una migration da cli con: 
    php artisan make:migration 'nome_tabella'
2. la migration verrà creata in database\migrations, aggiungi i dati che preferisci, stai molto attento perche per annullarla è complicato
3. ELIMINARE UNA MIGRATION SUBITO DOPO AVERLA FATTA
esegui: php artisan migrate:rollback
4.AGGIUNGI UNA COLONNA AL db
esegui: php artisan make:migration add_role_to_users_table --table=users
esempio per aggiungere role alla tab users:
public function up(): void
    {
        Schema::table('users', function (Blueprint $table) {
            $table->string('role')->after('password'); // Aggiungi la colonna 'role' dopo 'password'
        });
    }

    /**
     * Reverse the migrations.
     */
    public function down(): void
    {
        Schema::table('users', function (Blueprint $table) {
            $table->dropColumn('role');
        });
    }
